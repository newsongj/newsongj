# 주일보고 양식 v1

`sunday_report_v1.xlsx`는 가상 데이터로 구성한 9개 시트의 디자인 시안이다.
개인 원본 자료나 실제 명단을 포함하지 않는다. 이 파일은 앱과 함께 배포한다.

다운로드 시 아홉 시트 모두 기준 토요일과 그 앞 3주의 출석 기록, 기준일 소속으로 채운다.

- 1·2번: 팀별 출석·교구 합계·임원단·새가족·기수·등급·전주비. 팀장은 기준일 `팀장` 역할에서
  가져오고, 임원단은 팀별 인원에서 빼서 별도 행에 한 번만 더한다.
- 3·4·9번은 한 교구용 양식이다. 교구를 골라 받으면 그 교구로 채우고, 전체로 받으면
  교구마다 시트를 복제한다(`03_교구별그래프_1교구` 등, 그래프도 시트별로 복제).
- 3번: 팀장·이번 주 인원·4주 그래프(팀 인원, 교구 평균 = 교구 합계 / 12)·등반자.
- 4번: 지난주/이번 주 팀 인원과 이번 주 등반자·45기·46기·새가족 출석 명단. 새가족이 있는 팀만 초록색.
- 5~8번: 45·46기 기준일 출석 명단과 4주 추이. 임원단은 본인 팀에 넣어 1번 시트 기수 수와 맞춘다.
- 9번: 기준일 미등반 새가족과 이번 주 등반자를 한 칸에만 분류한다.
  우선순위는 이번 주 등반(출석/결석) → 이번 주 등록 → 결석(기록 없음 포함) → 교육 N주차 → 모임(교육 X).
- 등반자: `새가족` 프로필 이력이 있고 등반일이 지난 예배일 다음 날부터 기준 토요일까지인 사람.
  누적은 그 해 1월 1일부터 센다. 일반 멤버를 직접 추가해도 `enrolled_at`이 채워지므로 이력 조건이 필요하다.

정해지지 않은 칸은 비우거나 고정값으로 둔다. 래사랑·방문자·새가족 `주일` 등록 줄은 빈칸이고,
2025·2024년 비교 수치는 매주 100, `교역자·실행위원·직원·게스트 + 인원 보정`은 0이다.
두 번째 시트 `뉴송예배 실제수 인원`은 항목명만 남기고 `D51:H51`을 비운다. 수기 증감 사유도 비운다.
안건 목록은 개인 문서 `MDs/tasks/sunday-report-agenda.md`에 번호로 관리한다.
기존 첫 시트 `E64`의 확인용 출석 수와 기준일·범위 표시도 유지한다.

양식은 파일을 열 때 전체 재계산한다(`fullCalcOnLoad`). 다른 시트를 참조하는 수식 중
생성기가 같은 기준으로 채우지 않는 칸은 값으로 바꾼다. 남긴 수식의 캐시는 생성 값과 같아야 한다.
생성기는 각 시트·차트 XML만 수정하고 스타일·인쇄 설정 등 나머지 ZIP 항목을 보존한다.
명단 칸보다 이름이 많으면 마지막 칸에 쉼표로 이어 쓰고, 4번 시트는 행 높이를 늘린다.
양식의 시트 순서·칸 위치·인쇄 범위를 바꾸면 생성기와 다운로드 테스트도 함께 수정한다.
