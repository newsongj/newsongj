# 주일보고 양식 v1

`sunday_report_v1.xlsx`는 가상 데이터로 구성한 9개 시트의 디자인 시안이다.
개인 원본 자료나 실제 명단을 포함하지 않는다. 이 파일은 앱과 함께 배포한다.

다운로드 시 첫 시트의 `B64`에 실제 출석 라벨, `E64`에 선택 주간의 대시보드
출석 수, `F64`에 기준일·교구·팀을 넣는다. `A3`에는 나머지가 더미라는 안내를 넣는다.
기존 총인원·보정 인원·명단·차트는 아직 실제 데이터와 연결하지 않았다.

생성기는 이 고정 양식의 첫 worksheet만 수정하고 나머지 ZIP 항목을 보존한다.
양식의 시트 순서·확인 칸·인쇄 범위를 바꾸면 생성기와 다운로드 테스트도 함께 수정한다.
최종 보고서 집계 규칙이 정해지면 이 시험용 확인 칸을 정식 데이터 매핑으로 대체한다.
